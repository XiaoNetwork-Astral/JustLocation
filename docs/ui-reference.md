# 位置页菜单参考

2026-09-10，本轮按用户要求参考 Fake Location 1.5.2 的位置页菜单，采用现有 React 组件与主题实现。

## 参考来源

只读分析资料位于 `D:/temp/2026.9.1-FakeLocation/.codex`：

- `全功能分析/阅读副本/main/androidx/appcompat/view/widget/C3191.java.txt`：位置页独立模拟、基站和摇杆入口。
- `analysis/runtime-jadx-main/sources/androidx/appcompat/view/widget/C3818.java`：基站弹窗、开关、列表数量及坐标查询流程。
- `全功能分析/apktool-resources/res/values-zh/strings.xml`：中文菜单文案。

旧应用的独立模拟菜单包含启停独立模拟和选择应用两项，和位置模拟总开关分开。基站弹窗包含开关与列表数量，启用时可按所选坐标查询基站；图标状态还取决于是否存在基站数据。摇杆入口调用 RockerService 的开关，并检查悬浮窗权限。

## 当前实现

- 位置卡片右侧三个图标，分别打开独立模拟、基站和摇杆菜单。
- 独立模拟切换指定应用/全部应用，保留原有应用列表；模拟期间不能修改范围。
- 基站只做界面，启用按钮不可用，列表为空，并说明暂未接入。没有查询或修改基站的后台请求。
- 摇杆通过菜单设置最高速度、打开和关闭可选 App 的悬浮服务。首次使用由 App 完成权限授权，后续由面板集中控制。
- 总启停按钮等待后台响应再改变文字和颜色。颜色使用浅色/深色主题变量。
- 删除原来的独立摇杆卡片。路线页保留原有作用范围入口。

## 验证

前端单元测试覆盖作用范围保留、基站无后台操作和摇杆调用。浏览器测试覆盖 320 像素宽度下三个弹窗、两套主题、未收到启动响应时保持停止状态、收到响应后变色，以及打开/关闭摇杆的真实命令格式。浏览器里的 KernelSU 桥是测试替身，不能替代管理器和 Android 服务验收。

本轮未访问手机。此前真机已验证摇杆触摸移动、松手停止、贴边收起及 Android 定位接口输出；菜单布局和关闭服务返回码修复仍待下次连接手机后验收。
